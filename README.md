## 产品简介

幻金是一款运行在 Windows 上的财务数据分析工具，面向个人投资者、分析师和金融从业者。它可以读取 A 股上市公司公开披露的年报、中报和季报，在本地完成财报解析、财务指标计算、风险规则扫描、利润归因、同行对比和报告生成。

主要特点：

- 自动下载并解析公开财报，减少手工整理和录入。
- 展示资产负债表、利润表和现金流量表，并支持定位到 PDF 原文。
- 通过财务规则、组合信号和异常检测识别潜在风险。
- 提供一键尽调、财务概览、季度趋势、归因分析和跨公司对比。
- 支持生成年度分析报告，可将分析结论与原始披露内容相互核对。
- 可选接入大语言模型，生成辅助解读；不配置 AI 时仍可使用本地规则和报表功能。

所有分析结果均基于公开数据和自动化规则，仅供参考，不构成投资建议。

## 安装与启动

### 独立运行包

1. 下载最新 ZIP 文件。
2. 将 ZIP 完整解压到一个普通可写目录，不要在压缩包内直接运行。
3. 保持 `幻金.exe` 与 `_internal` 目录在一起，不要单独移动其中的文件。
4. 双击 `幻金.exe` 启动程序。

解压后的目录结构大致如下：

```text
DatasetAI.Standalone-<版本号>\
├─ 幻金.exe
└─ _internal\
```

如果 Windows SmartScreen 出现提示，请先确认安装包来自本仓库的 Releases 页面或 Microsoft Store，再决定是否继续运行。

### Microsoft Store

在商店页面点击安装，安装完成后从开始菜单搜索“幻金”即可启动。

## 快速使用

1. 打开“管理”页面，添加股票代码或名称，例如 `600519`。
2. 使用“一键同步”或“一键下载”获取公开财报数据。
3. 进入“财报分析”页面，选择公司、年份和报告期。
4. 使用“一键尽调”“财务概览”“年度报告”“归因分析”等功能查看结果。
5. 点击指标旁的溯源标记，可定位到对应的财报 PDF 页面进行核对。

## 数据与隐私

- 财报解析、指标计算、风险规则和报告生成默认在本机完成。
- 下载的财报、缓存和分析结果默认保存在本机工作区。
- 联网主要用于下载公开披露文件、更新市场数据以及用户主动启用的 AI 分析。
- AI 功能需要用户自行配置模型服务；启用后，相关分析文本可能发送给所配置的服务商。
- 不配置 AI 不会影响本地规则、财务概览、报表展示和 PDF 溯源。

Windows 默认数据目录：

```text
%LOCALAPPDATA%\DatasetAI\workspaces\
```

如需备份或迁移自选股、下载数据和分析结果，请备份整个工作区目录。升级或重新安装前，不建议删除该目录。

隐私政策：<https://datasetai.cn/privacy.html>

## 常见问题

### 解压后双击程序没有反应，或提示缺少文件

请确认 ZIP 已完整解压，并且 `幻金.exe` 与 `_internal` 目录仍位于同一目录。不要单独复制 EXE，也不要移动或删除 `_internal` 中的文件。

### 没有网络可以使用吗

已经下载并解析的数据可以离线查看，指标计算、规则扫描、财务概览和报告功能也可离线使用。下载财报、更新市场数据和 AI 分析需要联网。

### AI 功能不可用会影响其他分析吗

不会。AI 仅用于可选的自然语言摘要和解读。未配置 AI 时，本地规则、财务指标、风险扫描和 PDF 溯源仍可正常使用。

### 更新程序会删除已有数据吗

正常升级不会主动删除工作区数据。卸载、清理系统缓存或手动删除 `%LOCALAPPDATA%\DatasetAI\workspaces\` 可能造成数据丢失，操作前请先备份。

### 分析结果和原始公告不一致怎么办

请先以交易所和上市公司披露的正式公告为准。可以在问题反馈中提供股票代码、报告期、指标名称和截图，便于定位数据解析或规则问题。
